# 小型仓库货物出入库与库存预警系统

## 项目简介

本项目是使用 C 语言开发的小型仓库库存管理控制台程序，主要模拟货物信息管理、出入库操作与库存预警等基本业务。

通过该项目练习数据结构、函数设计、文件操作及基础业务逻辑的实现。

## 主要功能

- 管理仓库中的货物信息。
- 处理货物入库操作，更新库存数量。
- 处理货物出库操作，检查并更新库存。
- 查询货物及库存相关信息。
- 根据库存情况进行预警提示。
- 使用本地数据文件保存程序相关库存信息。

## 设计思路

**1. 货物信息管理**

以货物信息为基础组织库存数据，便于程序执行相关管理操作。

**2. 出入库处理**

入库操作增加相应货物的库存数量，出库操作根据现有库存判断是否可以完成，并更新库存数据。

**3. 库存预警**

根据货物的库存情况进行条件判断，对需要关注的库存状态给出提示。

**4. 本地文件存储**

项目使用本地数据文件保存库存信息。运行期间生成的数据文件不包含在 GitHub 源代码仓库中。

## 开发环境

- 编程语言：C
- 开发工具：Visual Studio
- 项目类型：Windows 控制台程序

## 运行方法

1. 下载或克隆本仓库。
2. 使用 Visual Studio 打开 `小型仓库货物出入库与库存预警系统.sln`。
3. 编译并运行项目。
4. 根据控制台菜单执行货物管理、出入库及库存查询等操作。
5. 查看库存变化与预警提示。

## 注意事项

- 出库时应注意库存数量是否满足要求。
- `warehouse.dat` 为程序使用的本地数据文件，不作为源代码上传。
- 本项目为课程设计作品，主要用于 C 语言和数据结构学习。

## 项目说明

本项目以小型仓库管理场景为基础，重点练习数据管理、模块化程序设计、条件判断及文件处理。
